# Clearance Guard

基于 **Altium EDA Agent（eda-agent 0.8.1）** 的实时避距（clearance / creepage）审核工具。

它不解析离线文件，而是通过 eda-agent 的 MCP 接口，直接读取**当前在 Altium Designer 中打开**的工程：
器件、焊盘、网络、原理图编译网表。随后自动判定每个网络属于原边（恒定 / 跳变）还是副边，
按自定义间距规则找出存在避距违规的器件，并给出**实测距离、要求距离与还差多少毫米**。

![界面概览](dev/shot_overview.png)

## 功能

| 模块 | 说明 |
|---|---|
| 工程扫描 | 读取当前工程文档、PCB 器件与焊盘、板级网络、原理图编译网表（引脚名用于拓扑推断） |
| 电压分类 | 依据网络名 + 网络拓扑（变压器 / 光耦隔离带、开关管、无源器件通路）自动判定：原边恒定、原边跳变（含跳变区间）、副边；无法判明侧别的按副边处理 |
| 图纸视图 | 每个原理图一个 Tab，列出该图纸的网络及其电压；跨页网络汇总到 common，再按功率侧 / 控制侧细分 |
| 参考地 | 驱动网络自动关联参考地（如 `18Vp-H1 → H1-GND`），并显示参考地的电压与跳变区间 |
| 安装焊盘 | 识别安装孔 / 安装焊盘，电位由用户指定（原边 / 副边、电压等级），指定后参与避距检查 |
| 无网络器件 | 识别没有任何网络的器件（磁芯、结构件），指定外形与电位后参与避距检查 |
| 电压修正 | 分类表可逐行改类别与电压上下限；置信度低或电压不明会标黄，改完即刷新，避距在「间距规则」页点「重新校验」 |
| 间距规则 | 3×3 类别间距矩阵 + 隔离带最小间距 + 按电压差增量 + 同器件内部 / 层 开关，可导出/导入 JSON |
| 违规计算 | 焊盘铜箔外沿两两求最小距离，输出器件对级与焊盘级结果，含缺口距离（mm） |
| 结果呈现 | 统计卡片、违规表（可排序筛选）、CSV 导出、布局视图高亮（按电压类别给焊盘着色，红圈标出违规） |
| 联动 Altium | 双击违规行可在 Altium 中定位对应器件（`proj_cross_probe`） |

## 环境要求

- Windows（Altium Designer 只在 Windows 上运行）
- Altium Designer 已打开需要审核的工程
- eda-agent 0.8.1 仓库与自带虚拟环境（默认 `E:\AI_model\eda-agent-0.8.1\.venv`）
- 运行本工具的 Python 3.10+，安装 PySide6

```bash
pip install -r requirements.txt
```

如果 eda-agent 不在默认位置，设置环境变量：

```bash
set EDA_AGENT_ROOT=E:\path\to\eda-agent-0.8.1
:: 或直接指定解释器
set EDA_AGENT_PYTHON=E:\path\to\eda-agent-0.8.1\.venv\Scripts\python.exe
```

## 启动

**双击 `run.cmd`** 即可。它会自动定位 Python（优先项目内 `.venv`，其次 `PATH` 里的
`python.exe` / `py -3`），检查 PySide6 与程序自身的导入，然后以 `pythonw` 启动（不弹黑框）。

也可以从命令行启动：

```bash
python app.py            # 正常启动
python app.py --demo     # 启动并载入内置示例（不连接 Altium）
python app.py --smoke    # 启动 2 秒后自动退出，用于自检
```

想双击直接看示例，可把 `run.cmd` 复制一份并改名为 `run-demo.cmd`，把最后一行改成
`python app.py --demo`；或新建快捷方式，在「目标」末尾加上 ` --demo`。

> 无 Altium 环境时，先点「示例工程」即可体验完整流程：内置一块 90 W 隔离反激电源板，
> 含 375 V 原边母线、0~375 V 开关节点、12 V / 5 V 副边与刻意做出的 4 处避距违规。

## 使用流程

1. **连接 Altium**：点击右上角「连接 Altium」。工具会以子进程方式启动 `eda-agent`（minimal toolset、headless），
   并通过 stdio 上的 MCP 协议驱动它。后台每 25 s 发一次 ping，避免 Altium 侧轮询因 10 分钟静默自动退出。
2. **选择工程并扫描**：下拉框列出 Altium 中已打开的工程；也可「打开工程…」指定 `.PrjPcb`。
   点击「扫描工程」。扫描分步显示进度，可取消（在当前步骤结束后生效）。
3. **核对电压类别**：在「工程与扫描 → 网络电压分类」复核。图纸视图里直接下拉改类别、双击改电压，
   或切到「全表编辑与确认」按名称搜索后批量修改。不需要逐项确认，改完直接往下走。
4. **配置间距规则**：在「间距规则」页设置矩阵、隔离带、电压差增量等，改动会自动保存到
   `%APPDATA%\ClearanceGuard\clearance_rules.json`。
5. **重新校验**：在「间距规则」页右下角点「重新校验」。结果在「违规结果」页，
   双击行可在 Altium 中定位；「导出 CSV…」输出完整清单。
   修改网络电压或规则都**不会**自动跑避距，只有点这个按钮才计算。
6. **布局视图**：按电压类别给焊盘着色（橙=原边恒定，红=原边跳变，青=副边），
   红圈标出违规位置，可缩放、平移、只看顶层/底层。

## 网络电压分类的图纸视图

顶层页签：**工程与扫描**（内含 扫描日志 / 网络电压分类 / 安装焊盘 / 无网络器件 四个子页签）、
**爬电隔离槽**、**间距规则**、**违规结果**、**布局视图**。
顶部「当前设计」栏常驻在全部页签之上：工程名、器件/焊盘/网络数量、各类别统计与图纸清单。

「网络电压分类」子页签分为两个内层 Tab：

- **按原理图图纸**：每个 `.SchDoc` 一个 Tab，Tab 标题形如 `Pri_Driver (2/6)`（本页专属 / 本页合计）。
  表内列出该图纸**专属**网络及电压类别、电压等级、参考地、置信度、判定依据；
  跨页网络不在这里重复出现，页头会用一行文字列出「跨页网络（见 common）」。
  该视图**可直接编辑**：电压类别是常驻下拉框，电压等级 / 上下限双击单元格修改；
  改动与「全表编辑与确认」共享同一批对象，两边始终一致，参考地电压会随被引用网络自动刷新。
  按类别锁定字段：**恒定电平只能改电压等级**（上下限自动等于它），
  **跳变电平只能改上下限**（电压等级自动跟随峰值）。
  人工修改过的网络，置信度列显示 **绿色对勾 ✓**（悬停可看原自动置信度），并随快照保存。
  最后一列 **跟随网络** 是下拉框（可直接输入网络名筛选，弹层最多 10 行）：给 `NetD10_1`
  这类自动命名的网络指定一个「有名字」的网络，
  选定后类别、电压等级、上下限、参考地、驱动标记**完全跟随**该网络（判定依据写「跟随 X」）；
  目标网络后来改了电压，跟随者下次刷新 / 校验时自动同步。跟随关系随快照保存，
  目标不存在时自动清空。全表编辑页也有同一列。
  恒定电平改「电压等级」时上下限自动跟随；把类别改成「副边」时，若还没有更具体的参考地，
  自动填 **SGND**（板上有名称为 SGND 或含 SGND 的网络时）。
- **全表编辑与确认**：平铺的全部网络，适合按网络名搜索后批量修改。

图纸 Tab 的第一个是 **common · 跨页网络**：出现在 2 张及以上图纸的网络只显示一次，
内部再分两个子 Tab：

| 子 Tab | 判定依据（按优先级） |
|---|---|
| 功率侧 | 接地/母线名称 → 开关节点（原边跳变）→ 连接功率器件（变压器、开关管非栅极脚、整流二极管、电感、连接器、保险丝、压敏）→ 原边 ≥24 V 母线 |
| 控制侧 | 名称含 PWM / GATE / DRV / FB / COMP / CS / ALERT / 通信等控制信号标识；其余信号网络 |

两侧可以互相转移：在子 Tab 右上角点「移到控制侧 / 移到功率侧」，支持多选（Ctrl / Shift）。
人工指定的侧别优先于自动判定，会写进判定依据（「人工指定为控制侧（自动判定：功率侧）」），
并随快照保存；点「重新自动分类」才会清掉。

图纸 Tab 右上角有「整页设为副边」：一键把该图纸上的**全部网络**（含跨页汇总到 common 的）
设为副边，参考地自动填 SGND、置信度显示 ✓。



数据来源：`obj_query(object_type="eSchComponent", scope="doc:<路径>")` 读取每张图纸的器件
（不切换 Altium 当前视图），再与编译网表的 `component/pin_name/net` 关联。
多通道设计（同一图纸被实例化多次，如 `SR_Cout` 的 14 个通道）用
`proj_get_hierarchy` 返回的编译实例名（`U_SR_Cout14`）把带后缀的位号
（`Q9_U_SR_Cout14`）归到正确的图纸；这类图纸会把各通道的网络合并显示在一个 Tab 内。

## 界面设计

深色数据密集型面板（PySide6 + QSS），令牌集中在 `clearance_check/ui/theme.py`：

| 令牌 | 值 | 用途 |
|---|---|---|
| `BG` / `SURFACE` / `CARD` | `#0F172A` / `#131C2E` / `#1B2336` | 底 / 表与面板 / 卡片，三层递进 |
| `BORDER` / `BORDER_STRONG` | `#26334A` / `#475569` | 分隔线 / 焦点与强边界 |
| `TEXT` / `MUTED` | `#F8FAFC` / `#94A3B8` | 正文（对比度 15:1）/ 次级（7:1） |
| `ACCENT` | `#2563EB` | 唯一操作色（与白字 5.2:1），只用于主按钮与选中页签 |
| `OK` / `WARN` / `DANGER` | `#22C55E` / `#F59E0B` / `#EF4444` | 安全 / 警告 / 危险，仅承担语义 |

- **类别色只表达电压性质**：橙=原边恒定、红=原边跳变、青=副边，与操作色互不混用；
- 表头 `#17223A` + 12px 次级色，正文 13px，行高紧凑，数字用等宽字体（`QSS` 里的 `JetBrains Mono / Cascadia Mono`）；
- 所有可交互控件都有可见焦点环（`QPushButton:focus`、输入框 `:focus` 描边 `ACCENT`）；
- 复选框对勾由 `_CheckStyle`（`QProxyStyle`）**用 QPainter 直接绘制**，不依赖图片——
  本机 DLP 会把 QSS 引用的 PNG 变成密文，图片型 indicator 会失效；
- 空状态、提示文字、状态栏统一 `MUTED`，不使用 emoji 作为图标。

## 上传到 GitHub（绕开 DLP）

本机 DLP 透明加密会让 `git.exe` 读到密文（文件头 `%TSD-Header-###%`），仓库里就是乱码。
`scripts/gh_upload.py` 与参考实现 `libviewer/gh_upload.py` 用同一套机制：
**Python 读明文 → GitHub REST API 建 blob / tree / commit / ref**，完全不用 git。

**图形界面**：双击根目录的 `上传到GitHub.cmd`（不带参数时打开窗口），或

```bash
python scripts/upload_gui.py
```

窗口里填 Token、仓库名（默认 `clearance-guard`）、可见性、提交说明，
可勾选「同时发布 Release」并添加附件；按钮：

- **先看会传什么**：本地列出全部文件与字节数，不联网；
- **开始上传**：后台线程执行，日志实时滚动，完成后可直接「打开仓库」；
- Token 可选「记住」，保存在 `%APPDATA%\ClearanceGuard\gh_token.txt`（不写进工程目录，不会被上传）。

命令行方式：

```bash
# 只看会传什么（不联网，默认目录也已排除）
python scripts/gh_upload.py --dry-run

# 首次上传（自动建库）
python scripts/gh_upload.py --token ghp_xxx --repo clearance-guard --public

# 以后每次改完
python scripts/gh_upload.py --token ghp_xxx --repo clearance-guard -m "修安装孔外径"

# 发版本 + 附件
python scripts/gh_upload.py --repo clearance-guard --release v1.0.0 \
       --asset doc\说明.pdf
```

参数：`--token`（或 `GITHUB_TOKEN`）、`--repo`、`--root`、`--public/--private`、
`-m/--message`、`--branch`、`--release/--release-notes/--asset`、`--no-proxy`、`--retries`。

- **工程根自动识别**：脚本在 `scripts\` 下运行时取上一级（判据：有 `app.py` 与
  `clearance_check\`）；也可用 `--root` 或环境变量 `CLEARANCE_ROOT`。
- **上传内容**：根目录几个文件 + `clearance_check/`、`tests/`、`scripts/`、`assets/`；
  `json/`（真实设计快照）、`dev/`、`__pycache__`、`scripts/_*.py`（一次性补丁）自动排除。
- **明文检验**：每个文件上传前检查文件头，命中 `%TSD` 或前 4KB 含 NUL 直接拒绝并给出处理办法。
- 也可以双击根目录的 `上传到GitHub.cmd`：不带参数时只做 dry-run，带参数时原样转发给脚本。

## 扫描快照（避免重复扫描）

大型工程扫描一次要 1~2 分钟（器件 25 s、焊盘 17 s、网表编译 25 s、图纸与安装焊盘若干秒）。
「工程与扫描」页提供两个按钮：

- **导出快照…**：把当前结果存成单个 JSON，包括板/器件/焊盘/网络、原理图引脚、图纸归属、
  安装焊盘电位，以及每个网络的电压类别、上下限与**参考地**。
  默认文件名带时间戳，形如 `VPDB_A4_scan_20261113_111101.json`，多次导出不会互相覆盖。
- **导入快照…**：直接还原上述全部内容，接着做复核或间距校验，不需要 Altium 在线。
- **导入快照…**：直接还原上述全部内容，接着做复核或间距校验，不需要 Altium 在线。
  导入的同时，这份快照会自动成为**配置基线**：下次扫描工程时，同名网络沿用它的类别、
  电压、参考地、侧别与人工标记，新增网络按本次自动分类（日志会写明「按配置基线 … 套用」）。
  也就是说，不再需要单独的「套用快照配置」按钮——导入一次即可长期沿用。
  ⚡ **增量分类**：已有基线时重新扫描只对新增网络做自动分类，其余直接沿用；
  若全部网络都在基线内则完全跳过分类。点「重新自动分类」可清除基线。
  导入快照时，板上有但快照里没有的网络也会自动补一份分类（工程改动新增的网络）。

另外：

- 每次扫描成功后会**自动保存**到 `%APPDATA%\ClearanceGuard\last_scan.json`，关闭程序时再存一次；
- 下次启动自动恢复上次扫描，状态栏会注明快照时间，可直接复核，也可重新「扫描工程」；
- 快照带格式标识与版本号，版本过新或文件不是本工具的会明确报错，不会静默加载脏数据；
- 导入后「在 Altium 中定位」仍可用（需要连接 Altium 且工程已打开）。

快照只存必要字段。按 735 器件 / 2261 焊盘 / 254 网络 / 2283 引脚的规模实测：约 710 KB，
保存 0.01 s、加载 0.02 s，基本相当于“瞬间打开”。

## 判定逻辑

### 侧别（原边 / 副边）

1. 网络名中的强标识：`PRI / HV / HVDC / PFC / BULK / DCLINK` → 原边；`SEC / ISO / SECOND` → 副边。
2. 结构上识别隔离器件：`T/TR/X` 前缀且 ≥4 焊盘（变压器）、光耦（`OC/OPT` 前缀或注释含 OPTO/PC817/TLP…）。
3. 用并查集沿**非隔离**器件把侧别扩散到相邻网络（电容、电阻、电感、二极管、IC 等）。
4. 变压器 / 光耦两侧绕组的焊盘按编号自然排序对半划分，已定的一侧给另一侧补上相反的侧别。
5. 既无侧别标识、也无隔离器件时，整板按单域（原边）处理，并在提示中说明——避免非隔离电源被误判出 8 mm 隔离违规。

### 0Ω ~ 10Ω 电阻（等电位直连）

`R/L/FB/F/J` 等器件阻值 **≤ 10 Ω** 时按等电位直连处理（`0R`、`0`、`R010`、`4R7`、`10R`，
也兼容 `0R 1/16W 0402` 这种带功率的写法）：两端网络的**类别、电压、上下限、参考地、
驱动标记**取信息更全的一侧，另一侧照抄（方向规则见下），判定依据里注明
「经 R11（0Ω）与 18Vp-H1 等电位」。

- `0R05`（5 mΩ 采样电阻）、`4R7`、`10R` 都算直连；`11R`、`10K`（10 kΩ）、`1M` 不算；
- **二极管（D / DZ / ZD / TVS / LED）**：只在「一端有命名、一端是自动命名」时建立跟随，
  自动命名端跟随命名端（如 `D4` 把 `18Vp-H1` 与 `NetD4_2` 连起来，后者跟随 `18Vp-H1`）；
  两端都有命名时（整流管 `SEC_GND ↔ Vout`、TVS `PMbus ↔ SGND`）不合并，避免把 0 V 并到输出上。
- **电感 / 磁珠 / 保险丝 / 跳线 / 网络连接件（L、FB、BEAD、F、JP、NT）也算直流直通**：
  例如 `L3`（`LQM21PN1R0NGRD 1uH/700mA`）把 `5Vs` 与 `NetC23_2` 连在一起，后者会自动跟随 `5Vs`；
  但**电感一端是开关节点时不做合并**（SW 与输出不是同一电位），接插件（`J`、`P`、`CN`）也不算直连；
- 扫描分类、导入快照、套用历史配置三条路径都会执行这一步；
- 方向受约束：**自动命名的网络只能跟随有命名的网络**，反向绝不允许——有命名网络
  （`PGND`、`12Vs`…）永远不会被 `NetR10_2` 这类网络锁住；命名侧还没有电压信息时，
  也不会把自动命名网络的值反向灌进来；但**仍会为自动命名的另一侧建立跟随关系**，
  等命名网络后面有电压时再同步。
- 该关系同时记为**跟随**：分类表「跟随网络」列直接显示对方网络（如 `NetC56_1 → 18Vp-H1`），
  之后目标电压变更会自动同步，也可以像手工跟随一样手工取消；
- 实测 R11 两端：`18Vp-H1` 与 `NetC56_1` 都是 `418 ~ 818 V`、参考地 `H1-GND`。

### 电压与跳变区间

- 名称中显式电压：`+24V`、`3V3`、`12V5`、`VCC12` 等。
- 无显式电压时，沿电容 / 电感 / 磁珠 / 保险丝等无源通路继承相邻网络电压（置信度下调）。
- 开关节点：名称含 `SW / LX / PHASE / DRAIN / BOOT / NODE`，或连接开关管漏极 / 变压器绕组 → 判为跳变电平，
  跳变区间取 `0 ~ 同侧最高母线电压`；栅极 / 驱动信号上限按 20 V 估计。区间可在界面上手动修改。
- 接地网络（`GND / PGND / SGND / AGND / 0V` 等）电压记 0 V。
- 置信度 < 0.6 或电压不明 → 标记「待确认」，请人工指定。

## 驱动网络与参考地

驱动类网络（`18Vp-H1`、`12Vs`、`GATE`、`Vgs_x` 等）除电压外还要给出**参考地**：
同一个 18 V 驱动电源，挂在高边源极 `H1-GND` 上时，其绝缘要求与挂在 `PRI_GND`
上完全不同。表格中的字段为：

| 网络名 | 电压类别 | 电压等级 (V) | 参考地网络 | 参考地电压 |
|---|---|---|---|---|
| 18Vp-H1 | 原边 · 恒定电平 | 18 | H1-GND | 0 ~ 800 V（跳变） |
| 12Vs | 原边 · 恒定电平 | 12 | SGND | 0 V |

参考地的判定顺序：

0. **开关管 Kelvin 源极**（最可靠）：栅极网络的参考点直接取被驱动开关管的 `DS/KS` 引脚网络，
   例如 `Vgs_p_H1 → Q1.DS = H1-GND`。驱动供电（`18Vp-*`）再由驱动 IC 的地脚落到同一网络。
1. **同名域**：`18Vp-H1` → 名称里的 `H1` 与 `H1-GND` 配对（`18Vp-L2 → L2-GND`）。
2. **同器件参考**：驱动芯片的 `GND/GNDISO` 引脚、开关管的 `S/E` 源极所在的网络；
   按「栅极/驱动脚 + 地脚」打分，取最高分。
3. **无源通路**：经电容 / 稳压管 / 电阻另一端接地（`12Vs` 经 C39/C40 到 `SGND`）。
4. **兜底**：同侧主地，并在判定依据里注明「建议确认」。

参考地电压直接取该网络自身的分类结果，所以把 `H1-GND` 的范围改成 `400 ~ 800 V`
后，所有引用它的驱动网络会立即显示同一区间。上下限填反了（例如下限 800、上限 400）
会自动纠正，不会退化成「范围待确认」。

**参考地跳变时，驱动网络本身也是跳变的**：网络电位是「参考地 + 本地电平」。
例如 `18Vp-H1` 比参考地高 18 V，参考地 `H1-GND` 是 400~800 V 跳变，所以它的绝对电位是
418~818 V，归为原边·跳变电平；栅极信号 `Vgs_p_H1`（相对 0~18 V）则是 400~818 V。
没有更具体参考地时按类别补默认值：**副边 → SGND**、**原边恒定 → PGND**（地网络自身不设参考地）；
驱动网络仍优先用器件给出的参考点（Kelvin 源极等）。

参考地恒定（`L2-GND = 0 V`、`SGND = 0 V`）时保持恒定，但同样加上参考地电压：
`18Vp-L2 = 18 V`、`12Vs = 12 V`；`L1-GND` 若是 400 V 恒定母线，则 `18Vp-L1 = 418 V`。
改了参考地的上下限后，表格会立即按新值刷新这些绝对电位（不需要跑避距校验）。

隔离驱动地（`GNDISO`/Kelvin 源极）是否跳变按开关管拓扑判断：功率源极接桥臂中点的那只
是**高边管**，它的 Kelvin 源极跟着中点跳（`H1-GND = 400~800 V`）；漏极接中点的那只是
**低边管**，参考点恒定（`L2-GND = 0 V`）。当母线同时是另一桥臂的中点（例如 400 V 母线
既是一段的输出、又是下一段的输入）时，同一只管子会被判成两种角色，此时按保守口径标为
「跳变 + 需确认」，并在判定依据里写明原因，不做猜测。

电压名解析支持 `18Vp` / `12Vs` / `3V3` / `1V8` / `+24V` / `VCC12` 等写法；
`Vgs`、`VPDB`、`H1-GND` 这类不含数值的不会被误读。

## 安装焊盘

安装孔/安装焊盘通过螺钉连接到机壳、散热器或某段母线，**电位不由板上网络决定**，
因此单独扫描、单独指派：

- 扫描时额外读取板上不属于器件的自由焊盘（`obj_query(ePadObject, InComponent=false)`），
  以及没有网络、孔径 ≥ 1.5 mm 的器件焊盘，作为安装焊盘候选。
- 「安装焊盘」页为每个候选给出一行：位置、**孔径**、**外径**、板上原网络、电位归属、电压上下限、是否参与检查。
  外径取自焊盘的实际铜箔尺寸（Altium `TopXSize/BotXSize`），例如 1.8 mm 孔径的安装孔外径为 **3.5 mm**；
  **避距按外径计算**（孔径只用于识别安装孔与展示），外径不大于孔径时会标黄提示。
- 电位归属**默认按副边**处理（机械结构通常接在副边/机壳），可改成原边并填电压；
  勾选「参与检查」即作为独立对象参与避距计算，违规结果里以 `MH1` 这样的名称出现。
- 安装焊盘按通孔处理，顶/底层都参与比较。

## 无网络器件（磁芯 / 结构件）

有些器件在 PCB 上**没有任何网络**——例如嵌在板上的磁芯 `T38`（`aux_core`，0 个焊盘），
但它的磁芯/金属体靠近高压 MOS 的漏极，仍然有爬电要求。这类器件单独列在「无网络器件」页：

- 扫描时自动识别：**所有焊盘都没有网络**，或者干脆没有焊盘的器件；
- **外形尺寸由 PCB 桥接读取**（器件包围盒 `bbox_no_name_comment`，已按旋转/正反面取轴对齐外框），
  页面上只读显示，例如 `T38 = 10.38 × 7.26 mm`；读不到外形的行显示「未读到外形」并且不参与检查；
- 每行可指定：电位归属（原边恒定 / 原边跳变 / 副边）、电压与上下限、是否参与检查；
- 未指定电位的行不参与检查（行首位号标黄提示）；
- 指定后以位号出现在违规结果里（`T38 ↔ R5` 这样的组合）；
- 设置随快照保存。

## 板框外形

每次扫描都会读取 PCB 板框（pcb_get_board_outline），圆弧按 6° 离散成多边形，存入 Board.outline（mm）。实测与「VPDB_A4 板框外形记录.html」一致：50 个原始顶点 = 35 线 + 15 弧，外形 240.00 × 41.50 mm。「布局视图」按它绘制真实板形，并随快照保存。

## 板级挖空（避距槽 / 圆形孔）

扫描时读取板上 `Kind = board_cutout` 的区域（`obj_query eRegionObject` + `Bounds*`）：

- **圆形挖空** → 自动加入「安装焊盘」页，命名为 `CH1`、`CH2`…，外径 = 孔径，
  备注写明「板级挖空（圆形 Øx.xx mm）」，默认按副边处理，可逐行改电位或取消参与；
- **多边形挖空** → 作为**避距槽**参与间距判定（见下），并显示在「爬电隔离槽」页。

### 「爬电隔离槽」页

列出所有避距槽（序号、中心、长×宽、顶点数、轮廓是否已读取），右侧显示所选槽的
**闭合轮廓顶点坐标**（mm，逐点一行，首尾自动闭合），可「复制坐标」。

轮廓坐标需要遍历整板铜箔（`pcb_get_copper` 分页，实测 5800 条 / 约 30 秒），
所以**不放进常规扫描**：点右上角「读取轮廓坐标」单独读取，读到后按中心与尺寸
自动配对到对应槽，并随快照保存。间距计算用槽的外框，不依赖这些顶点。

原副边之间的判定因此分成两条：

| 情况 | 判据 | 默认值 |
|---|---|---|
| 两点之间没有避距槽（沿面） | **爬电距离** | 8.00 mm |
| 两点之间被避距槽隔开、且绕槽沿面 ≥ 爬电距离 | **电气间隙**（直线） | 6.00 mm |
| 跨槽但绕槽沿面仍不足 | 仍按爬电距离 | 8.00 mm |

绕槽沿面路径按槽的外框（矩形）估算：`入槽直线 + 沿槽口较短一侧的周长 + 出槽直线`。
规则页可分别调整这两个值。

## 间距规则

- **类别矩阵**：3×3（原边恒定 / 原边跳变 / 副边），默认值：
  同类 0.20 mm，原边恒定↔原边跳变 0.50 mm，原边↔副边 8.00 mm（隔离带）。
- **隔离带爬电距离（沿面）**：原边↔副边默认 **8.00 mm**（没有避距槽时按此判）。
- **隔离带电气间隙（跨避距槽）**：默认 **6.00 mm**，被板级挖空隔开且绕槽沿面达标时用这个值。
- **器件间最小间距（与网络无关）**：默认 **0.30 mm**，适用于**任何两个不同器件的焊盘**，
  不看网络、不看电压类别（同一网络的两个器件焊盘也照样检查）。可在规则页关闭或改数值。
- **电压差增量**：默认每 100 V 增加 0.50 mm，与矩阵值取较大者（用于 375 V 对 0 V 这类场景）。
- 其它开关：是否只检查跨类别、是否检查同一器件内部焊盘（隔离器件内部始终检查）、是否纳入走线。

距离按**铜箔外沿到外沿**计算；不同层（顶层 / 底层）的焊盘不构成间距问题，通孔焊盘按两层都参与。

## 违规输出

- **器件级（推荐）**：每对器件保留最严重的一条，字段为器件位号、网络、类别组合、实测距离、要求距离、
  **缺口 = 要求 − 实测**、坐标、依据规则、**类型**。
- **类型（严重级别）**：
  - `ERROR`：**不同器件**的焊盘之间违规（记入红色统计，需要优先处理）；
  - `WARNING`：**同一器件内部**焊盘违规（例如隔离器件内部爬电），提示性。
  工具栏的「类型」下拉可只看 ERROR 或只看 WARNING。
- **焊盘级明细**：精确到 `位号.焊盘名`，便于定位。
- CSV 导出包含器件级全量字段（UTF-8 BOM，Excel 可直接打开）。

## 精度与限制

- **坐标**：eda-agent 返回 mil，本工具统一换算为 mm（1 mil = 0.0254 mm）。
- **焊盘外形**：默认按外接矩形近似。矩形焊盘精确；圆形 / 椭圆 / 八边形焊盘会略微放大（偏保守，
  可能把「刚好够」判成「差一点」）。如需精确外形，可调用 `pcb_get_pad_properties` 逐网络取 `shape`
  （`clearance_check/eda/session.py::pad_shapes_by_net` 已实现，全量调用较慢，默认关闭）。
- **器件内部焊盘**：默认不参与器件间避距检查，但隔离器件（原边↔副边）内部始终检查——变压器的
  引脚间爬电正是最需要关注的地方。
- **走线**：接口已支持 `Track`（胶囊体几何），但当前未从 eda-agent 拉取走线，默认只算焊盘。
- **性能**：`pcb_get_components` 在 Altium 侧要遍历全部器件并计算包围盒，实测 735 器件的板子约 25 s；
  焊盘按 60 个器件一批读取，约 17 s；原理图网表编译约 25 s（可在扫描选项里跳过）。界面全程后台线程 + 进度提示。
- **桥接**：Altium 侧脚本轮询在无客户端 10 分钟后自动退出。工具会保活；若仍失效，
  失败提示里可直接选择「自动启动脚本桥」（等价于 `eda-agent relaunch --restart`）。

## 排错

| 现象 | 处理 |
|---|---|
| 「Altium 脚本未响应」 | 在 Altium 中 File → Run Script… → `Altium_API` → `Dispatcher.pas` → `StartMCPServer`，或让工具自动 `relaunch` |
| 连接时报「无法启动 EDA Agent」 | 确认 `EDA_AGENT_ROOT` / `EDA_AGENT_PYTHON` 指向带依赖的 eda-agent 虚拟环境 |
| 扫描很慢 | 大板读取器件本身要 20~30 s；可先跳过原理图网表；确认 Altium 未被模态对话框阻塞 |
| 分类结果整板都是原边 | 该板没有隔离变压器 / 光耦，工具按单域处理；可在分类表中把输出侧网络手动改为「副边」，再重新校验 |
| 违规太多 | 提高「最小缺口」过滤、勾选「只看隔离带」，或调小同类间距 |

本工具仅通过 Altium 官方脚本接口读取设计数据，不修改原理图与 PCB。使用前请自行备份工程。
